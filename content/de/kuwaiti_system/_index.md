## Zusätzliche Informationen


Das in Saudi-Arabien und Kuwait verwendete Braille-System ist nahezu identisch mit der
türkischen Braille-Sprache.

Die genau übereinstimmenden Punkte sind die folgenden. Diese Punkte sind dieselben wie
die im zweiten Teil behandelten Lektionen:

1.  Das arabische Alphabet

2.  Die Vokalzeichen (Harakat)

3.  Sukun und Dschazm

4.  Die Hamza-Varianten

5.  Ta Marbuta


## Madd-Dehnungen

Im arabischen System ist die Braille-Form der Madd-Dehnungen dieselbe wie im türkischen
System. Im arabischen System gibt es jedoch keine verborgenen Madd-Dehnungen.
Stattdessen wird nur ein Vokalzeichen gesetzt.

## Tanwin

Auch wenn das Tanwin in beiden Systemen auf dieselbe Weise geschrieben wird, gibt es hier
ein kleines Detail. Das Fatha-Tanwin wird in der Regel zusammen mit einem Alif
geschrieben. Im türkischen System wird das Fatha-Tanwin nach dem Alif geschrieben, im
arabischen System hingegen genau umgekehrt.

## Alif-Dehnungen

Alif-Madd und Alif Maqsura werden in beiden Systemen gleich geschrieben, und außerdem
wird die Waw-Alif-Dehnung im arabischen System nicht verwendet. Stattdessen wird ein Alif
geschrieben.
